# Magnetic IDE downloads

Installers for the Magnetic AI coding IDE. Get the newest version from the
[latest release](https://github.com/MegneticAi/magnetic-releases/releases/latest).

| Platform | Download |
| --- | --- |
| macOS (Apple Silicon: M1 and newer) | [Magnetic-darwin-arm64.dmg](https://github.com/MegneticAi/magnetic-releases/releases/latest/download/Magnetic-darwin-arm64.dmg) |
| Linux x64 (AppImage, any distro) | [Magnetic-linux-x64.AppImage](https://github.com/MegneticAi/magnetic-releases/releases/latest/download/Magnetic-linux-x64.AppImage) |
| Linux x64 (Debian/Ubuntu .deb) | [Magnetic-linux-x64.deb](https://github.com/MegneticAi/magnetic-releases/releases/latest/download/Magnetic-linux-x64.deb) |

## Install

**macOS:** open the `.dmg` and drag Magnetic into Applications. This build is not notarized yet: the
first time, right-click Magnetic in Applications and choose **Open**, then **Open** again.

**Linux AppImage:** `chmod +x Magnetic-linux-x64.AppImage` then run it.

**Linux .deb:** `sudo apt install ./Magnetic-linux-x64.deb`
